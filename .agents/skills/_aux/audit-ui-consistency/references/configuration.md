# Configuration

[Return to the UI consistency audit](../SKILL.md).

Compare effective-setting explanations. Different risks and scopes may justify different recovery policies.

## Checks

- Identify effective values, scopes, and overrides.
- Distinguish global, trusted-project, and session-only changes.
- Match diagnostics to invalid or unknown settings, silent fallback, field recovery, and disabled features.
- Compare defaults, accepted values, normalisation, and disabled states across the UI and documentation.
- Match reload and restart instructions to when settings are read.
- Identify save destinations and distinguish saved values from overridden effective values.

## Evidence

Use disposable valid and invalid settings with competing scopes. Record actual behaviour and diagnostics. Recommend consistent explanations; recommend identical fallback only for equivalent contracts.
