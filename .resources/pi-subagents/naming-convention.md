Task names: `[Type] phrase`, such as `[Research] lease ownership`. Use 2 to 4 words after the type, put the word that differs from other tasks first, and keep names unique. No IDs, models, roles, or status words. On resume, keep the phrase; change the type only if the work changes.

- `[Research]`: changes no files.
- `[Edit]`: changes files; also mixed work.
- `[Verify]`: runs checks; reports failures without fixing them.

The type is only a label; state the same limit in the prompt. Jobs: no type, the purpose in 3 to 5 words, such as `Watch unit tests`.
