## Working agreement

- Create all worktrees under `.worktrees`.
- After changes, follow the [verification workflow](docs/agents/verification.md) before handoff.

## Task references

Read the matching reference before starting that work:

- **Reuse** — behavior changes or refactors: [architecture](docs/agents/architecture.md).
- **Tests** — coverage decisions or test edits/reviews: [testing](docs/agents/testing.md).
- **Development** — validation, TypeScript/tooling edits, package setup, dependencies, pi API work, or local loading: [development](docs/agents/development.md).
- **Commits** — composing a commit message: [commit conventions](docs/agents/commits.md).
- **Setup** — installing the workspace or resolving prerequisites: [README.md](README.md).
