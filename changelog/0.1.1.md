# 0.1.1 - 2026-10-23

## Breaking changes

- Targets Pi 1.4.0 or later. (5ec32e0)
- Extensions behave identically in any load order, whatever the order in `pi.extensions` or `settings.json`. (d176300)
- Conflicting workspace extension shortcuts register neither key and show one warning. (d176300)
- pi-tool-display stops using `pi-tool-display/calls/` files and `pi-tool-display.writer` entries (existing files from 0.1.0 can be deleted), and replays 0.1.0 `pi-tool-display.call` entries without an operation status. (8599892)

## Added

- pi-subagents: `job` accepts `hold_run: true` to keep the run busy until the job's result arrives (including in print, JSON, and child runs), showing "Waiting for background results" in the working message. See [held jobs](../packages/extensions/pi-subagents/docs/jobs.md#held-jobs). (05d0656)
- New user guides: [pi-tool-display tool cards](../packages/extensions/pi-tool-display/docs/tools.md), [pi-profiles tools](../packages/extensions/pi-profiles/docs/tools.md), [pi-profiles sessions](../packages/extensions/pi-profiles/docs/sessions.md), and [pi-nested-instructions input discovery](../packages/extensions/pi-nested-instructions/docs/input-discovery.md). (5a7b08a)

## Changed

- pi-abort-guard: wraps the existing editor's input handling instead of replacing the editor. (d176300)
- pi-editor-widgets: sorts unlisted widgets by ID per region and unlisted statuses by ID in code-unit order. (d176300)
- pi-profiles: keeps `deny` tools off for the whole selection (even when another extension, `tool_search`, or `--tools` re-enables them, and across `/tree`, `/fork`, and resume) and orders declared tools with Pi's built-ins first, then others by name. (d176300, 5ec32e0)
- pi-smart-compact and pi-subagents: register tools at load so a profile that turned them off keeps them off. (d176300)
- pi-smart-compact: drops its custom split-turn focus wrapper (Pi 1.4.0 handles custom instructions) and stops sending `maxTokens` on summary requests. (5ec32e0)
- pi-tool-display: uses Pi's recorded durations ("Exit N · <time>" for shell, "Took <time>" for codemode) across forks, reloads, and machines; retains aborted and timed-out shell previews until reload, session change, or exit, and nonzero-exit previews across reopen. (8599892)
- pi-session-utils: saves an automatic title only after its run settles without an abort. (733a4ab)

## Fixed

- pi-abort-guard: resets interrupt confirmation when a run, compaction, or tree navigation starts. (b2925ef)
- pi-agent-summary: marks file statistics unavailable when another writer modifies a file, and caches session usage and context projections until the session, leaf, entry count, or model changes. (48c955f)
- pi-editor-widgets: forwards mouse focus to the keyboard-handling widget, and preserves rows containing only styled spaces. (48c955f)
- pi-fff-guard: matches globs over full paths as in FFF 0.11.0, includes `/` in bracket expressions like `[.-0]` and negated ranges, allows links into ignored destinations that FFF searches, and reports missing directory roots behind brace patterns. (42fc49d, 08fe3d2)
- pi-nested-instructions: resolves Pi's Windows drive aliases to the same scope as the tool. (30794b8)
- pi-null-args: leaves calls unchanged when the schema uses `not`, `const`, `enum`, or `minProperties`. (42fc49d)
- pi-profiles: shows denied search tools as off in Tools view while pi-profiles owns `tool_search`, and checks `deny` before saved deferrals. (d242887, 543ea7f)
- pi-prompt-manager: starts clipboard helpers in their own process group so **Ctrl+Z** does not stop them (`wl-copy`), keeps collections with non-finite values read-only and checks own properties including `__proto__` before rewrites, waits on shutdown for cancelled transaction locks, stops equivalent launch keys from disabling each other, and keeps a new section's query when input arrives before render (also in the pi-profiles menu). (5ec32e0, 34eef6f, c4be1f6)
- pi-session-utils: discards a pending automatic title on aborted runs or replaced/cancelled naming. (b2925ef, 733a4ab)
- pi-skills: matches only complete skill references so path suffixes do not block template expansion, and wraps the default expansion destination in angle brackets for paths with spaces or parentheses. (30794b8)
- pi-smart-compact: stops claiming existing context was preserved after a failed compaction. (47469ce)
- pi-subagents: waits for all runs on root shutdown and reports failed process cleanup, keeps `show --last` JSON within the output budget, and sanitises child text in the task viewer. (e0f9485)
- pi-todo: includes bounded, terminal-safe metadata in `get` (escaping DEL and C1 controls), and restricts collapse/expand/toggle to confirmed fullscreen mode including empty lists. (47469ce, 543ea7f)
- pi-tool-display: isolates rows whose hooks fail outside groups and summaries, uses the final tool name after message-end renames, shares one preview budget across MCP text blocks, and keeps inline diff emphasis on later line pairs of large hunks (also in pi-agent-summary). (beb156a, bd4112f, c845228)
- Shared behaviour: settings saves through symlinks lock the symlink target, and shortcut keys invoke the latest accepted owner's handler. (c4be1f6, ac1ac12)

## Workspace

- Moves Pi development packages to ^1.4.0 and Vite+ to 1.4.0, with refreshed catalog versions. (5ec32e0, 58c5e56)
- `@pi-mono/libs` adds `input-chain`, `prompt-parts`, and `lifecycle` coordinators; `registerWorkingMessage` requires `ownerRank`. (d176300)
- Release workflow publishes only while its commit is `master` head, queues pending jobs, and pins `actions/checkout` and `actions/setup-node` to commit SHAs. (04c2590, 5185950)
- Lint rejects value imports of Pi host packages in native worker entries; `vpr docs:check` checks bold bullet labels, testing guide structure, and "Last verified" lines; the pre-commit hook allows em dashes in `.agents/skills/`. (04c2590, 5a7b08a)
- Adds the `implement` skill and locked auxiliary skills under `.agents/skills/_aux`; `code-review` never modifies locked skills. (3ecf949, 5a7b08a, 361fe87)
- Website respects `prefers-reduced-motion` for anchor scrolling. (04c2590)
