# 0.1.1 - 2026-10-23

## Breaking changes

- The extensions require Pi 1.4.0 or later. ([5ec32e0](https://github.com/pnd280/pi-mono/commit/5ec32e0dfc0fb4fae6fb1e035f0f4ad6f9d891d7))
- The extensions give the same result in any load order, whatever the order in `pi.extensions` or `settings.json`. ([d176300](https://github.com/pnd280/pi-mono/commit/d176300bb23f21f6b6886d616084df3d3533707b))
- When two workspace extensions claim shortcut keys that can match one keypress, neither extension registers its key, and Pi shows one warning for the conflict. ([d176300](https://github.com/pnd280/pi-mono/commit/d176300bb23f21f6b6886d616084df3d3533707b))
- pi-tool-display no longer writes or reads files under `pi-tool-display/calls/` in Pi's agent directory, and no longer writes `pi-tool-display.writer` entries. Files from 0.1.0 stay on disk; you can delete them. ([8599892](https://github.com/pnd280/pi-mono/commit/8599892acff82085d1afc4bdbd4ab52687c0e017))
- pi-tool-display replays `pi-tool-display.call` entries from 0.1.0 without an operation status. ([8599892](https://github.com/pnd280/pi-mono/commit/8599892acff82085d1afc4bdbd4ab52687c0e017))

## Added

- pi-subagents: the `job` tool takes an optional `hold_run` boolean. A held job keeps the run busy until its result arrives, so print, JSON, and child runs also receive the result. While the run waits, the working message shows "Waiting for background results". See [held jobs](../packages/extensions/pi-subagents/docs/jobs.md#held-jobs). ([05d0656](https://github.com/pnd280/pi-mono/commit/05d065625f540c4502021281b4c185e540a9f2b1))
- New user guides: [pi-tool-display tool cards](../packages/extensions/pi-tool-display/docs/tools.md), [pi-profiles tools](../packages/extensions/pi-profiles/docs/tools.md), [pi-profiles sessions](../packages/extensions/pi-profiles/docs/sessions.md), and [pi-nested-instructions input discovery](../packages/extensions/pi-nested-instructions/docs/input-discovery.md). ([5a7b08a](https://github.com/pnd280/pi-mono/commit/5a7b08a6840cac390c6cd868933eed3befd99d28))

## Changed

- pi-abort-guard wraps the input handling of Pi's editor, or of an editor that another extension set, instead of replacing the editor. ([d176300](https://github.com/pnd280/pi-mono/commit/d176300bb23f21f6b6886d616084df3d3533707b))
- pi-editor-widgets sorts unlisted widgets by ID in each region. Unlisted statuses sort by ID in code unit order, whatever the locale. ([d176300](https://github.com/pnd280/pi-mono/commit/d176300bb23f21f6b6886d616084df3d3533707b))
- pi-profiles keeps `deny` tools off for the whole selection, also when another extension, `tool_search`, or `--tools` turns them on again, and after `/tree`, `/fork`, and resume. ([d176300](https://github.com/pnd280/pi-mono/commit/d176300bb23f21f6b6886d616084df3d3533707b), [5ec32e0](https://github.com/pnd280/pi-mono/commit/5ec32e0dfc0fb4fae6fb1e035f0f4ad6f9d891d7))
- pi-profiles puts the declared tools in a fixed order: Pi's own tools first, then the other tools by name. ([d176300](https://github.com/pnd280/pi-mono/commit/d176300bb23f21f6b6886d616084df3d3533707b))
- pi-smart-compact and pi-subagents register their tools at load, so a profile that turned them off keeps them off. ([d176300](https://github.com/pnd280/pi-mono/commit/d176300bb23f21f6b6886d616084df3d3533707b))
- pi-smart-compact no longer adds its own focus to split-turn prompts, because Pi 1.4.0 adds custom instructions to them. ([5ec32e0](https://github.com/pnd280/pi-mono/commit/5ec32e0dfc0fb4fae6fb1e035f0f4ad6f9d891d7))
- pi-smart-compact summary requests no longer send `maxTokens`, so summaries use the model's output limit. ([5ec32e0](https://github.com/pnd280/pi-mono/commit/5ec32e0dfc0fb4fae6fb1e035f0f4ad6f9d891d7))
- pi-tool-display takes durations from Pi's results instead of its own timers. Shell cards show "Exit N · <time>" and codemode cards show "Took <time>", also after a fork, a reload, or on another machine. ([8599892](https://github.com/pnd280/pi-mono/commit/8599892acff82085d1afc4bdbd4ab52687c0e017))
- pi-tool-display keeps the preview of aborted and timed-out shell calls until `/reload`, a session change, or exit. Shell calls with a nonzero exit code keep their preview after you reopen the session. ([8599892](https://github.com/pnd280/pi-mono/commit/8599892acff82085d1afc4bdbd4ab52687c0e017))
- pi-session-utils saves an automatic title only after its run settles without an abort. ([733a4ab](https://github.com/pnd280/pi-mono/commit/733a4ab41df30255d38d3f5af7cad7388df45bbe))
