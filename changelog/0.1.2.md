# 0.1.2 - 2026-10-25

## Breaking changes

- pi-subagents: the built-in `subagent` tool description states only how tasks work and no longer tells the model when to delegate. To give the model a delegation rule, list a file in the [`docs`](../packages/extensions/pi-subagents/README.md#configuration) setting. The workspace's [delegation file](../.resources/pi-subagents/delegation.md) is an example. (19d7502, 00d1073)

## Added

- pi-subagents: the `shortcut` setting in `ext.pi-subagents` sets the key that opens the task panel, in Pi key syntax. The default stays `ctrl+alt+s`. The setting rejects **Esc** and function keys with a modifier, and an invalid value is ignored. See [configuration](../packages/extensions/pi-subagents/README.md#configuration). (603a646)
- pi-subagents: each child's system prompt tells the child that its supervisor receives only its final reply. It asks for the outcome first, then evidence as file paths with line numbers or as commands and their results, then what the child did not verify or finish. See [result instructions](../packages/extensions/pi-subagents/docs/children.md#result-instructions). (19d7502)
- New user guides: [pi-model-prompt rules](../packages/extensions/pi-model-prompt/docs/rules.md), [pi-nested-instructions loading rules](../packages/extensions/pi-nested-instructions/docs/loading.md), [pi-profiles settings](../packages/extensions/pi-profiles/docs/configuration.md), [pi-profiles menu](../packages/extensions/pi-profiles/docs/menu.md), [pi-profiles switches](../packages/extensions/pi-profiles/docs/switching.md), [pi-skills skill-reference rules](../packages/extensions/pi-skills/docs/rules.md), [pi-smart-compact compaction requests](../packages/extensions/pi-smart-compact/docs/requests.md), [pi-subagents child processes](../packages/extensions/pi-subagents/docs/children.md), and [pi-todo controls](../packages/extensions/pi-todo/docs/controls.md). (3a514e2)

## Changed

- pi-editor-widgets: the `/widgets` menu follows Pi's `tui.select.up`, `tui.select.down`, `tui.select.confirm`, and `tui.select.cancel` keybindings instead of fixed keys. A remapped selection key takes a menu key such as **a** or **Tab**, but never **Ctrl+S** save or **Ctrl+C** close. The hints and the empty-row text show only the keys that reach their action. See [usage](../packages/extensions/pi-editor-widgets/README.md#usage). (f00dcb2)
- The `/working-message` menu follows Pi's `tui.select.up`, `tui.select.down`, and `tui.select.cancel` keybindings, with the same precedence and hints as `/widgets`. See [working-message ordering](../packages/libs/src/working-message/ordering.md#settings-menu). (f00dcb2)
- Key hints in all workspace menus and browsers show a letter without modifiers in lowercase, such as `k`, because a capital letter reads as Shift plus that letter. Arrow keys with the same modifiers share one hint, such as `Shift+↑↓`. (f00dcb2)
- pi-subagents: the `background` parameter description no longer tells the model not to poll. The notices for a started or updated background task still do, in plain case instead of capitals. (19d7502)
- READMEs keep the overview and move rules, limits, and edge cases to the user guides. Docs now match the code for limits, units, behaviour, and test coverage. The pi-subagents README shows a banner. (3a514e2, 9a50efb, 83f114c, 1a4d964, 72414b7)

## Fixed

### pi-subagents

- The task panel and the task viewer update the context use of an active task after each completed response, instead of showing 0 tokens for a new task until its run ends. After a compaction, the tokens are unknown until the next response, as Pi counts them. (152450d)
- An open transcript of a live task reloads after the child compacts its context. (eb566f2)

### pi-tool-display

- The warning about unavailable mode cycling names the key bound to `app.tools.expand` instead of always **Ctrl+O**, and says when that keybinding has no key. (549f6b0)

### Shared behaviour

- The native-tool compatibility check hashes the real source of Pi's methods, so a method with its own `toString` can no longer hide a changed Pi method. This applies to pi-tool-display and pi-agent-summary. (955f6eb)
- pi-fff-guard, pi-nested-instructions, and pi-tool-display recognise an FFF tool under `node_modules` only when its path is the installed `@ff-labs/pi-fff` package, not a copy inside another package. (e573448)

## Workspace

These changes affect forks and local development, not the `release` branch.

- The release job does not run in forks, so a fork publishes no `release` branch or tags. (70187e5)
- `@pi-mono/libs` adds `KeyControls` to `tui/keybindings`, which gives a view its dispatch, labels, and hints from Pi keybindings and fixed keys. The shared browser, the subagent panel, and the todo browser use it. (f00dcb2)
- Modules with one consumer move to that consumer: `@pi-mono/libs` no longer exports `private-files`, which moves to pi-prompt-manager, or `tui/components/diff-view`, which moves to pi-tool-display with `fast-diff`. `@pi-mono/utils` moves `shell` to pi-session-utils and adds `provenance`. pi-agent-summary no longer exports `./milestones`. (e573448)
- Membership checks use sets typed with Pi's unions, or `===` comparisons, so a misspelt member fails the type check. Mirror types come from their source, and calls with positional booleans take named objects. (e6bf3e1, 79e6547)
- `check-docs.ts` stops when Pi's manifest has no version, instead of using "undefined". (79e6547)
- Lint allows value imports of `@earendil-works/pi-ai/models`, which Pi 1.4.0 supplies to installed extensions. (95145fd)
- The private-file transaction test accepts either lock order for concurrent transactions on separate queues, which removes an intermittent failure. (7aea70c)
- Agent docs get sharper pointers, positive rules, and checkable verification steps. The `typescript-taste` skill asks for union-typed sets in membership checks, `typescript-review` asks why checks accepted each defect, and `code-review` reports each phase with its status and results. (3a514e2, 6587ac6, 45c78be)
