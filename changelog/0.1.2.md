# 0.1.2 - 2026-10-25

## Breaking changes

- pi-subagents: the built-in `subagent` tool description no longer tells the model when to delegate; add a delegation file via [`docs`](../packages/extensions/pi-subagents/README.md#configuration) (see the example in [delegation.md](../.resources/pi-subagents/delegation.md)). (19d7502, 00d1073)

## Added

- pi-subagents: `ext.pi-subagents.shortcut` configures the task panel key (default `ctrl+alt+s`, rejecting modified **Esc** and function keys). See [configuration](../packages/extensions/pi-subagents/README.md#configuration). (603a646)
- pi-subagents: appends [result instructions](../packages/extensions/pi-subagents/docs/children.md#result-instructions) to each child's system prompt asking for outcome first, evidence, and unverified or unfinished items. (19d7502)
- New user guides: [pi-model-prompt rules](../packages/extensions/pi-model-prompt/docs/rules.md), [pi-nested-instructions loading rules](../packages/extensions/pi-nested-instructions/docs/loading.md), [pi-profiles settings](../packages/extensions/pi-profiles/docs/configuration.md), [pi-profiles menu](../packages/extensions/pi-profiles/docs/menu.md), [pi-profiles switches](../packages/extensions/pi-profiles/docs/switching.md), [pi-skills skill-reference rules](../packages/extensions/pi-skills/docs/rules.md), [pi-smart-compact compaction requests](../packages/extensions/pi-smart-compact/docs/requests.md), [pi-subagents child processes](../packages/extensions/pi-subagents/docs/children.md), and [pi-todo controls](../packages/extensions/pi-todo/docs/controls.md). (3a514e2)

## Changed

- pi-editor-widgets and `/working-message`: menus follow Pi's `tui.select.up`, `tui.select.down`, `tui.select.confirm` (`/widgets`), and `tui.select.cancel` keybindings (keeping **Ctrl+S** and **Ctrl+C** protected), and hints show only active keys. See [pi-editor-widgets usage](../packages/extensions/pi-editor-widgets/README.md#usage) and [working-message ordering](../packages/libs/src/working-message/ordering.md#settings-menu). (f00dcb2)
- Key hints across workspace menus and browsers show unmodified letters in lowercase (such as `k`) and merge arrow pairs with the same modifiers (such as `Shift+↑↓`). (f00dcb2)
- pi-subagents: moves the no-polling reminder out of the `background` parameter description while keeping it in background start/update notices in plain case. (19d7502)
- Docs: moves detailed rules, limits, and edge cases from READMEs into user guides and aligns docs with code; adds a banner to the pi-subagents README. (3a514e2, 9a50efb, 83f114c, 1a4d964, 72414b7)

## Fixed

- pi-subagents: updates active task context usage in the task panel and viewer after each completed response, and reloads an open live transcript after child compaction. (152450d, eb566f2)
- pi-tool-display: mode-cycling warnings name the key bound to `app.tools.expand` (or report when unbound) instead of hardcoding **Ctrl+O**. (549f6b0)
- Shared behaviour: native-tool compatibility hashes the real method source (defeating custom `toString` in pi-tool-display and pi-agent-summary), and FFF tool detection in pi-fff-guard, pi-nested-instructions, and pi-tool-display requires the installed `@ff-labs/pi-fff` package path. (955f6eb, e573448)

## Workspace

- Release workflow no longer runs in forks. (70187e5)
- `@pi-mono/libs` adds `KeyControls` in `tui/keybindings` for the shared browser, subagent panel, and todo browser. (f00dcb2)
- Moves single-consumer modules to their owners (`private-files` → pi-prompt-manager, `tui/components/diff-view` + `fast-diff` → pi-tool-display, `shell` → pi-session-utils), adds `@pi-mono/utils/provenance`, and removes `pi-agent-summary/milestones`. (e573448)
- Types membership sets with Pi unions, derives mirror types from source, replaces positional booleans with named options, stops `check-docs.ts` when Pi's manifest lacks a version, and allows value imports of `@earendil-works/pi-ai/models`. (e6bf3e1, 79e6547, 95145fd)
- Fixes intermittent lock-order flakiness in the private-file transaction test, and sharpens agent docs and skills (`typescript-taste`, `typescript-review`, `code-review`). (7aea70c, 3a514e2, 6587ac6, 45c78be)
