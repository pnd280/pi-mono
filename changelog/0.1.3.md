# 0.1.3 - 2026-11-03

## Breaking changes

- Targets Pi 1.5.0. Update Pi with `pi update` before you run `pi update --extensions`, or install the `v0.1.2` tag to stay on Pi 1.4.0. See [Install](../README.md#install). (9013726)

## Added

- pi-skills: typing `/` at the start of a whitespace-separated token (outside the start of the first line) opens an inline skill picker that filters by text and inserts `/skill:<name>` without submitting. See [completion](../packages/extensions/pi-skills/docs/rules.md#completion). (79130fb)
- Shortcut settings in pi-prompt-manager, pi-profiles, and pi-subagents accept modified function keys **F1**–**F12** (such as `alt+f5`); modified **Escape** stays invalid. (9013726)

## Changed

- pi-profiles: stops reordering declared tools (Pi 1.5.0 preserves active tool order) so enforcement only disables `deny` tools. (9013726)
- pi-prompt-manager: ranks fuzzy search results with Pi 1.5.0 scores. (9013726)
- Key hints on pi-read results, pi-subagents task cards, and pi-tool-display subagent result cards follow your Pi keybindings. (9013726)
- In pi-prompt-manager, the pi-profiles menu, and the todo browser, a configured action that takes a fixed key keeps it and the footer shows "<label> unavailable" for the fixed action. (156a08a)
- Docs deduplicate rules into root docs and tighten phrasing. (68a965b, db54cae)

## Fixed

- pi-fff-guard: passes `-c core.fsmonitor=false` to Git so untrusted repository config cannot run commands. (5d71838)
- pi-prompt-manager: starts clipboard helpers from `/` so WSL can launch `powershell.exe` when cwd exceeds Windows `MAX_PATH`. (9013726)
- pi-session-utils: `/sesh persist` preserves copied entry labels, including cleared labels. (c08cad4)
- pi-smart-compact: a rule setting only `thinkingLevel` no longer passes pre-resolved credentials, letting stored OAuth logins apply. (9013726)
- pi-subagents: submitting an unedited editor dialog returns the child's prefill; cancelling or ending a run closes open select/confirm/input dialogs and drops late answers from forwarded editor dialogs ([dialogs](../packages/extensions/pi-subagents/docs/children.md#dialogs)); Windows immediate stops wait for `taskkill`, avoid concurrent `taskkill` runs, and retain capacity until the child exits if forced stop fails. (756882e)
- pi-tool-display: stops showing an empty notice when a compact diff displays every row of a hunk, removes duplicate "Saved output" references on native results, warns "Script output truncated; expand to inspect retained output." on truncated saved codemode output, and recognises Pi's confirmation text when paths contain escaped characters. (6a8f530)
- Shared behaviour: pi-agent-summary and pi-tool-display record writes through dangling symlinks under the link target (156a08a), and output tails in pi-tool-display saved output and pi-subagents job logs skip at most three leading continuation bytes before showing further invalid bytes as `�`. (9c28c81)

## Workspace

- Moves Pi development packages to ^1.5.0, imports `Type` and `Static` from `typebox` 1.3.27 (declared as a host peer in `@pi-mono/libs` and pi-read), and drops `@tanstack/router-cli`. (9013726, d914dee)
- Adds public contracts `pi-smart-compact/result` and `pi-subagents/details` for pi-tool-display validation. (d48f488, 756882e, 6a8f530)
- `@pi-mono/utils` adds `errors` (`hasErrorCode`, `errorMessage`), `paths.windowsDrivePath`, and moves `shell` back from pi-session-utils. (9c28c81, 20ac8e5)
- `@pi-mono/libs` replaces `readScopedSettings` with `readScopedSections`, adds `formatRunningDuration`, `inspectedSource`, `hookCompatible`, `TUI_GLYPHS.returned`, and `PATCH_QUEUE_BYTES`, removes the type-only browser entry, makes `formatKeyLabel` and `navigationHints` private, and fixes prototype walking in owned-hook lookup, `AggregateError` reporting in interactive-host `dispose`, and empty `text_start` blocks in the validation provider. (20ac8e5, 156a08a)
- Removes adapter resolver exports from `pi-tool-display/adapters` and the codemode/MCP adapter modules. (20ac8e5)
- Adds root `tsconfig.json`, converts `count-tests` to TypeScript, switches root `test` to `vp test run`, caps Vitest to 4 workers / 2 concurrent tests per file, drops the website `tsr generate` script, extends `fingerprints:check` to pi-skills, and updates `implement` and `code-review` skills. (8760b75, 2b6aff8, d914dee, 79130fb, bbccd25, e434707)
- The test suite goes from 731 tests in 0.1.2 to 655 after merging e2e scenarios and removing duplicates. (2b6aff8)
