# 0.1.3 - 2026-11-03

## Breaking changes

- The extensions require Pi 1.5.0. pi-smart-compact checks for Pi 1.5.0 at session start, and pi-tool-display and pi-editor-widgets check the Pi 1.5.0 method fingerprints. (9013726)
- pi-prompt-cloak matches only the Pi 1.5.0 system prompt wording, so on Pi 1.4.0 it rewrites nothing. (9013726)

## Added

- pi-skills: typing `/` at the start of a whitespace-separated token opens a skill picker, but not at the start of the first line. The text after `/` filters the skills, and accepting inserts `/skill:<name>` without submitting. A `/` at the start of the prompt still opens Pi's slash-command picker. If the installed Pi version isn't supported, or an earlier extension provides an editor that isn't Pi's, `/` opens no picker and Pi shows one warning. See [completion](../packages/extensions/pi-skills/docs/rules.md#completion). (79130fb)
- Shortcut settings in pi-prompt-manager, pi-profiles, and pi-subagents accept modified function keys **F1** to **F12**, such as `alt+f5`, because Pi 1.5.0 can dispatch them. Modified **Escape** stays invalid. (9013726)

## Changed

- pi-profiles no longer puts the declared tools in a fixed order, because Pi 1.5.0 keeps the order of active tools. Enforcement now only turns off `deny` tools. (9013726)
- pi-prompt-manager ranks fuzzy search results with Pi 1.5.0 scores, so the order of results differs from 0.1.2. (9013726)
- Key hints on pi-read results, pi-subagents task cards, and pi-tool-display subagent result cards use the keys from your Pi keybindings. (9013726)
- In pi-prompt-manager, the pi-profiles menu, and the todo browser, a configured action that takes a fixed key shows "<label> unavailable" in the footer. (156a08a)
- Docs state each rule once, with workspace rules in the root docs, and use shorter sentences, lists, and numbered steps. (68a965b, db54cae)

## Fixed

### pi-fff-guard

- Git calls pass `-c core.fsmonitor=false`, so inspecting a path in an untrusted repository can't run a command from that repository's configuration. (5d71838)

### pi-prompt-manager

- Clipboard helpers start from `/`, as Pi 1.5.0 does, so WSL can start `powershell.exe` when the current directory path is longer than the Windows `MAX_PATH` limit. (9013726)

### pi-session-utils

- `/sesh persist` keeps the labels of the copied entries, including a cleared label, so a label changed on another branch is neither stale nor lost. (c08cad4)

### pi-smart-compact

- A rule that sets only `thinkingLevel` no longer sends pre-resolved credentials to Pi's session stream, so a stored OAuth login applies to the summary request. (9013726)

### pi-subagents

- An editor dialog that you submit without changes returns the child's own prefill, not the shown text. An edited answer is sent unchanged. (756882e)
- When a run is cancelled or ends, its open select, confirm, and input dialogs close, and the child gets a cancellation. Pi gives extensions no way to close an editor dialog, so a forwarded editor stays open, and its late answer is dropped. See [dialogs](../packages/extensions/pi-subagents/docs/children.md#dialogs). (756882e)
- On Windows, an immediate stop waits for `taskkill` and starts no second `taskkill` while one runs. When a forced stop fails while the child still runs, the child keeps its capacity slot until it exits. (756882e)

### pi-tool-display

- Compact diffs no longer show an empty notice when the preview shows every row of a hunk. (6a8f530)
- Native results no longer show a duplicate "Saved output" reference. (6a8f530)
- Codemode cards show a "Script output truncated; expand to inspect retained output." warning when Pi truncated and saved the output. (6a8f530)
- Native cards recognise Pi's confirmation text when the path contains characters that the card escapes. (6a8f530)

### Shared behaviour

- pi-agent-summary and pi-tool-display record a write through a dangling symlink under the link's target. (156a08a)
- The output tails of pi-tool-display saved output and pi-subagents job logs skip at most three continuation bytes at the start, and show further invalid bytes as `�`. (9c28c81)

## Workspace

These changes affect forks and local development, not the `release` branch.

- The Pi development packages move to ^1.5.0. Pi 1.5.0's pi-ai no longer exports `Type` and `Static`, so code imports them from `typebox` 1.3.27, which `@pi-mono/libs` and pi-read declare as a host peer. The catalog drops `@tanstack/router-cli`. (9013726, d914dee)
- New public contracts: `pi-smart-compact/result` for compaction results and `pi-subagents/details` for task and job details. pi-tool-display validates these results with them instead of copied schemas. (d48f488, 756882e, 6a8f530)
- `@pi-mono/utils` adds `errors` with `hasErrorCode` and `errorMessage`, `windowsDrivePath` in `paths`, and `shell`, which moves back from pi-session-utils. (9c28c81, 20ac8e5)
- `@pi-mono/libs` replaces `readScopedSettings` with `readScopedSections`, and adds `formatRunningDuration`, `inspectedSource`, `hookCompatible`, `TUI_GLYPHS.returned`, and `PATCH_QUEUE_BYTES`. It removes the type-only browser entry, and makes `formatKeyLabel`, `navigationHints`, and the codemode and MCP display adapters private. (20ac8e5, 156a08a)
- `@pi-mono/libs` fixes: owned-hook lookup walks function prototypes, interactive-host `dispose` runs every cleanup step and reports all failures as one `AggregateError`, and the validation provider sends the empty `text_start` block that Pi expects. (156a08a)
- A root `tsconfig.json` type-checks `.scripts/`, the pi-update scripts, and `vite.config.ts`. `count-tests` is TypeScript, and the root `test` script runs `vp test run`, so it exits instead of watching. (8760b75)
- Vitest runs at most 4 workers and 2 concurrent tests per file. Merged e2e scenarios and removed duplicates take the suite from 726 to 652 tests. (2b6aff8)
- The website drops the `tsr generate` script, which removed routes from `routeTree.gen.ts`. (d914dee)
- The fingerprint check covers the pi-skills editor owner, and the private-method gate policy also covers private calls. (79130fb)
- Agent skills: the model can invoke `implement` once requirements are settled, and `code-review` runs all six audits before it applies revisions. (bbccd25, e434707)
