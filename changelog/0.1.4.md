# 0.1.4 - 2026-11-17

## Breaking changes

- Targets Pi 1.5.2. Update Pi with `pi update` before you run `pi update --extensions`, or install the `v0.1.3` tag to stay on Pi 1.5.0. See [Install](../README.md#install). (cbba1f5, 7db3d11)
- Removes FFF support: pi-fff-guard is deleted (remove `extensions/pi-fff-guard/index.ts` from `settings.json`, or pin `v0.1.3` to keep it), pi-tool-display drops `@ff-labs/pi-fff` cards, and pi-nested-instructions drops `fffind`, `ffgrep`, and `fff-multi-grep` input discovery. (f0ef68d)
- pi-profiles: restores a saved selection's tools and deferral only when current settings supply that profile from the same scope; selections saved by 0.1.3 lack scope and are ignored on resume (reselect with **Alt+I** or `/profile <name>`), while saved "no profile" selections still apply. (0b71b5b)
- pi-agent-summary: drops edited-file recording and `edited N files · +A -R` statistics; expanding a summary shows only the finish time. (aa57e00)
- pi-tool-display: changes the stored format for unavailable patches, so 0.1.3 calls with unavailable changes lose their saved display facts on reopen while Pi's arguments, results, and other calls still replay. (f846cf5)
- pi-read: highlights saved results from their recorded window, which can drop or shift highlights on 0.1.3 reads with `offset` above 1. (00bfad6)
- pi-subagents: ignores `maxDepth` or `maxConcurrent` above 100 (falling back to the other scope or default), and refuses to resume a task whose child session's real working directory differs from the supervisor's. (e1430cf, d60671e)

## Added

- pi-t3-skills: new extension (active when `T3_PI_MCP_EXTENSION_PATH` is set) that removes T3 Code's `<skill>` blocks and expands whitespace-separated `$<name>` skill chips using configurable `ext.pi-t3-skills.expansionFormat`, ordered cleanly alongside pi-skills. See [skill blocks](../packages/extensions/pi-t3-skills/docs/rules.md#skill-blocks) and [expansion format](../packages/extensions/pi-t3-skills/docs/rules.md#expansion-format). (3947095, 4991b8c)
- pi-subagents: adds `launch_args` on the `subagent` tool (and `requested_launch_args` in `/subagents list`), rejecting reserved/session flags and repeating previous arguments on resume unless overridden or cleared with `[]`. See [launch arguments](../packages/extensions/pi-subagents/docs/tasks.md#launch-arguments). (6d4a014, 7bf4aa7, d60671e)
- pi-subagents: adds named `templates` (inline or JSON file, global and trusted project) with `model`, `thinking`, `background`, `launchArgs`, and `appendSystemPrompts`, selectable via `template`, labelled `[<name>] …`, and surfaced in expanded task cards, the task viewer, and pi-tool-display subagent cards. See [templates](../packages/extensions/pi-subagents/docs/tasks.md#templates). (9973001, 69259db, 7bf4aa7, 5792898, 4cea079, d60671e)
- pi-profiles: profiles can define up to 32 MCP servers in `mcpServers` (no `auth` in project profiles), keeping unchanged connections across switches and following branch selections on resume, `/fork`, `/tree`, and `/reload`. See [profile MCP servers](../packages/extensions/pi-profiles/docs/tools.md#profile-mcp-servers). (1379749, 030f510)
- pi-editor-widgets: adds the hidden-by-default "Git changes" (`builtin:git-changes`) footer item showing unstaged, staged, and untracked counts in the TUI. See [git changes](../packages/extensions/pi-editor-widgets/docs/settings.md#git-changes). (4c7de0c)
- pi-smart-compact: adds `statusStep` (≥ 50000, or `0`/`null` to disable) to emit model-facing context usage notices at step multiples, rendered by pi-tool-display as compact "Context usage" rows. See [context status](../packages/extensions/pi-smart-compact/docs/configuration.md#context-status) and [context status rows](../packages/extensions/pi-tool-display/docs/tools.md#context-status-rows). (58d0d9f)
- pi-tool-display: closed runs in summary mode list up to eight created or edited files below the summary line with `A`/`M`, line counts, edit counts, and failed/cancelled markers. See [changed files](../packages/extensions/pi-tool-display/docs/presentation.md#changed-files). (55170d6)
- pi-subagents: adds a `context` row to the task viewer (showing a compaction spinner and compaction history, moving context use out of `usage`) and adds `outcome` and `error` to `/subagents show`. (74e9d7c, ec5b1b8)

## Changed

- Appends "Call this tool directly. It is not available inside codemode." to `subagent`, `subagent_abort`, `job`, `job_abort`, `todo`, and `compact` descriptions while `codemode` is declared. (1fbebb0)
- Shortens tool descriptions and guidelines in pi-todo, pi-read, and pi-subagents. (0de37ef, 423aa9a, f9c5809, bad9c9f)
- pi-subagents: prefixes `subagent` results with a warning when ignored fields were passed, shows task costs to three decimals (`$0.210`), brackets the active panel view (`[all 3]`), and places `status` and `error` ahead of `log` and `command` in the job viewer. (6d4a014, 7bf4aa7, ec5b1b8)
- pi-agent-summary: computes dimmed `tok/s` from Pi's measured response durations, and summarises runs cancelled on quit or session switch. (f4624ef, cbba1f5)
- pi-profiles: exact `/profile <name>` submits on the first **Enter**, unknown arguments show usage as an error, and menu details open with "Profile: <name>" or "Tool: <name>". (7d98ec2)
- pi-read: reads without `offset`, `limit`, or `selection` use Pi's native result rendering. (00bfad6)
- pi-null-args: leaves calls unchanged when the tool schema uses `oneOf` or `$dynamicRef`. (1488e74)
- pi-nested-instructions: ignores `time` and `!` Bash prefixes for scope discovery, and lets Pi report discovery errors at turn end or session start. (fbb4aa1, d71befb)
- pi-session-utils: auto-naming sends the model's projected context instead of the raw branch. (3fd5a15)
- pi-prompt-manager: speeds up search on long prompts with identical results. (4822422)
- pi-tool-display: shows unknown historical outcomes as "N unavailable", labels created writes "Created" even without a patch, shows retry counts on cancellation during retries, names disabled features in host warnings, drops all card notices on wrongly typed native or pi-mcp-adapter detail fields, and saves call facts with Pi's final result rather than on session close. (f846cf5, cbba1f5)
- Marks the active tab or scope as `[label]` in pi-profiles, pi-editor-widgets, and pi-prompt-manager menus. (64e32bf)
