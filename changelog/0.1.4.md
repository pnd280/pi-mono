# 0.1.4 - 2026-11-17

## Breaking changes

This version needs a newer Pi, removes FFF support, and changes how some saved sessions restore.

### Pi 1.5.2

- The extensions require Pi 1.5.2. On Pi 1.5.0 or 1.5.1, pi-smart-compact shows "pi-smart-compact: requires the inspected Pi 1.5.2 compaction implementation; unsupported version or conflicting runtime patch." in the TUI, and `compact` is unavailable. Print mode shows no message. (cbba1f5, 7db3d11)
- On Pi 1.5.0, pi-tool-display warns "pi-tool-display: private TUI host hooks unavailable; keeping original rendering." and keeps Pi's own tool rendering. pi-editor-widgets reports "unsupported Pi widget registry", stays inactive, and leaves Pi's own UI unchanged. Both still work on Pi 1.5.1. (cbba1f5)
- To upgrade, update Pi to 1.5.2 with `pi update` before you run `pi update --extensions`. To stay on Pi 1.5.0, install the `v0.1.3` tag. See [Install](../README.md#install).

### FFF support

- pi-fff-guard is removed. Nothing checks FFF searches for Git-ignored or missing targets any more, so such a search can again return nothing without saying why. If your package entry in `settings.json` lists `extensions/pi-fff-guard/index.ts`, remove it. To keep the guard, install the `v0.1.3` tag. (f0ef68d)
- pi-tool-display no longer has cards for `@ff-labs/pi-fff` tools. Those calls keep pi-fff's own renderer or get a generic card. (f0ef68d)
- pi-nested-instructions no longer discovers instructions from the inputs of `fffind`, `ffgrep`, and `fff-multi-grep`. An FFF tool named `grep` or `find` is read like Pi's native tool of that name. (f0ef68d)

### Saved sessions

- pi-profiles reapplies a saved selection's tools and deferral only when the current settings still supply that profile from the same settings scope. In an untrusted project, a selection of a project profile reapplies nothing, even when a global profile has the same name. A selection whose profile is no longer configured no longer reapplies its saved tools. (0b71b5b)
- pi-profiles ignores the profile selections that 0.1.3 saved, because they record no scope. When you resume such a session, switch the profile again with **Alt+I** or `/profile <name>`. A saved "no profile" selection still applies. (0b71b5b)
- pi-agent-summary no longer records or shows the files that a run edited. The summary line drops `edited N files · +A -R`, and expanding a summary shows only the finish time. Summaries saved by 0.1.3 still show, without file statistics. (aa57e00)
- pi-tool-display saves a change that has no patch in a new form. When you reopen a 0.1.3 session, a call that saved its change as unavailable (binary content, a change over the size limits, or an unreadable source) loses its saved display facts: cancellation, exit code, timeout, and the change. Pi's own saved arguments and results stay, and other saved calls still replay. (f846cf5)
- pi-read highlights a saved result from the window that it records. In a 0.1.3 session, a read with an `offset` above 1 can lose or misplace its highlight. The saved text is unchanged. (00bfad6)
- pi-subagents ignores a `maxDepth` above 100 or a `maxConcurrent` above 100, so the other settings scope or the default applies. (e1430cf)
- pi-subagents refuses to resume a task when the working directory of the task's child session is not the supervisor's working directory, for example after you fork the supervisor session in another directory. The check compares real paths. Resume such a task from a supervisor in that directory. (d60671e)

## Added

This version adds the pi-t3-skills extension and subagent templates, along with smaller features in other extensions.

### pi-t3-skills

- The new extension pi-t3-skills turns each `$<name>` skill chip from [T3 Code](https://github.com/pingdotgg/t3code) into a link to the skill's file, and removes the `<skill>` blocks with the skill contents that T3 Code adds. See [skill blocks](../packages/extensions/pi-t3-skills/docs/rules.md#skill-blocks). (3947095, 4991b8c)
- It does nothing unless the `T3_PI_MCP_EXTENSION_PATH` environment variable is set and not empty, as it is in sessions that T3 Code starts.
- A chip changes only when whitespace separates it and it names a registered skill exactly. A typed `/skill:<name>` stays for pi-skills.
- `ext.pi-t3-skills.expansionFormat` sets what a chip becomes. The default is `"[{command}](<{path}>)"`. The format must contain `{path}` and has at most 512 Unicode code points. A trusted project's value replaces the global one. See [expansion format](../packages/extensions/pi-t3-skills/docs/rules.md#expansion-format).
- With pi-skills, T3 Code's blocks are removed first, then pi-skills expands `/skill:` tokens, then the chips change, whatever the load order.

### pi-subagents templates and launch arguments

- The `subagent` tool accepts `launch_args`, extra Pi CLI arguments for the child, with at most 32 items of at most 2,048 characters. They come before the flags that the extension sets, so the extension's own flags win. See [launch arguments](../packages/extensions/pi-subagents/docs/tasks.md#launch-arguments). (6d4a014, d60671e)
- A call fails before it starts a task when an item of `launch_args` is `--`, or a flag that `model`, `thinking`, or the task session owns: `--model`, `--provider`, `--thinking`, `--session`, `--session-id`, `--no-session`, `--fork`, `-c`, `--continue`, `-r`, or `--resume`. It also fails when the last item is a Pi flag that needs a value. (6d4a014, d60671e)
- On a resume without a template, an omitted `launch_args` repeats the latest run's arguments, and `[]` clears them. (6d4a014, 7bf4aa7)
- The new `templates` setting holds named defaults for new tasks and resumes, and a `subagent` call names one with `template`. Each entry is a template object, or the path of a JSON file that holds one. A template has `name` and `description`, and optional `model`, `thinking`, `background`, `launchArgs`, and `appendSystemPrompts`. See [templates](../packages/extensions/pi-subagents/docs/tasks.md#templates). (9973001, 69259db, 7bf4aa7)
- `launchArgs` and `appendSystemPrompts` each hold at most 32 items of at most 2,048 characters. Relative prompt paths, and the path values of `-e`, `--extension`, `--skill`, `--prompt-template`, and `--theme` in `launchArgs`, resolve from the directory of the file that holds the template. (9973001, 69259db, d60671e)
- A template with an unknown field, an invalid value, a rejected launch argument, `--system-prompt` or `--append-system-prompt` in `launchArgs`, or an unreadable prompt file is left out with a warning. (9973001, d60671e)
- Global and trusted-project templates combine. A project template replaces a global template of the same name completely. (9973001)
- For `model` and `thinking`, a call value wins over the template, which wins over the latest run's value on resume, and then the supervisor's selection. For `background`, the call wins over the template, and the default is `false`. (9973001, 7bf4aa7)
- With a template, the child gets the call's `launch_args`, then the template's `launchArgs`, then an `--append-system-prompt <absolute path>` pair for each prompt file. On resume, these replace the arguments of the latest run. (9973001, 7bf4aa7)
- A call fails when it names an unknown template, or when its `launch_args` repeats a single-value flag that the template sets, such as `--tools` or `--session-dir`. (9973001)
- A template task's label starts with the template name, such as `[explorer] Lease ownership`. The `subagent` description lists each template's name, description, `model`, `thinking`, and `background`, without its launch arguments or prompt files. (5792898, 4cea079)
- Expanded task cards and the last row of the task viewer show the run's launch arguments as an exact JSON array, with control and text-direction characters as `\u` escapes. pi-tool-display subagent cards show them in an expanded `launch_args` field. (5792898)
- `/subagents list` items have a `requested_launch_args` field. (6d4a014)

### Other features

- pi-profiles: a profile can define up to 32 MCP servers in an optional `mcpServers` field, in the entry shape of Pi's `mcp.json`. Only the selected profile's servers are registered, an unchanged server keeps its connection across a switch, and resume, `/fork`, `/tree`, and `/reload` follow the branch's selection. A project profile whose server uses `auth` is skipped with a warning, as Pi does for a project `mcp.json`. See [profile MCP servers](../packages/extensions/pi-profiles/docs/tools.md#profile-mcp-servers). (1379749, 030f510)
- pi-editor-widgets: the new footer item "Git changes" (`builtin:git-changes`) shows the lines added and removed by unstaged changes, the same for staged changes, and the number of untracked files, as in `+42 -11  [+10 -2]  U 3`. It is hidden by default; add it in `/widgets`. Git runs only in the interactive TUI while the item is placed. See [git changes](../packages/extensions/pi-editor-widgets/docs/settings.md#git-changes). (4c7de0c)
- pi-smart-compact: the new `statusStep` setting adds a context usage message for the model each time usage passes a multiple of the step, such as `Context usage: {"tokens":152340,"contextWindow":200000,"percent":76.17}`. The value is a whole number of at least 50000, and `0` or `null` turns off an inherited step. The status never starts a request of its own, and the steps count from zero again after a compaction. See [context status](../packages/extensions/pi-smart-compact/docs/configuration.md#context-status). (58d0d9f)
- pi-tool-display shows the pi-smart-compact context status as one "Context usage" row with the same totals as the `context_window` card. See [context status rows](../packages/extensions/pi-tool-display/docs/tools.md#context-status-rows). (58d0d9f)
- pi-tool-display: in summary mode, a closed run lists the files that it created or edited below its line. Each row shows `A` or `M`, the path, and the lines added and removed by the successful calls. A file whose latest call failed or was cancelled shows "failed" or "cancelled" instead of `A` or `M`, and a file that several successful calls changed shows a count such as "3 edits". At most eight rows show, and files that a shell command changed get none. See [changed files](../packages/extensions/pi-tool-display/docs/presentation.md#changed-files). (55170d6)
- pi-subagents: the task viewer has a `context` row. It shows a spinner while a direct child compacts, and the number of compactions on the viewed branch with the context tokens before the latest one. The `usage` row no longer shows the context use. (74e9d7c)
- pi-subagents: `/subagents show` adds `outcome`, and `error` when the run has one. (ec5b1b8)

## Changed

- While the codemode tool is declared, the descriptions of `subagent`, `subagent_abort`, `job`, `job_abort`, `todo`, and `compact` end with "Call this tool directly. It is not available inside codemode." (1fbebb0)
- The tool text is shorter. pi-todo describes `todo` as "Manage a todo hierarchy." and drops two guidelines. pi-read keeps Pi's `read` description and one guideline. The pi-subagents `job` description and start result are shorter, and the `subagent` and `job` description parameters give no word count. (0de37ef, 423aa9a, f9c5809, bad9c9f)
- pi-subagents: the `subagent` result starts with a warning line when the call set fields that it ignored, such as `model` for a running task. (6d4a014, 7bf4aa7)
- pi-subagents: task costs show three decimals, such as `$0.210`, in the task panel and on task cards. (ec5b1b8)
- pi-subagents: the task panel shows the current view in brackets, such as `[all 3]`. (ec5b1b8)
- pi-subagents: the job viewer shows `status` and `error` before `log` and `command`, so a long command no longer pushes them out of view. (ec5b1b8)
- pi-agent-summary computes `tok/s` from the response durations that Pi measures, and shows the rate dimmed. When you quit Pi or switch sessions during a run, Pi 1.5.2 cancels the run, and the run gets a summary. (In 0.1.3 the unfinished run was discarded.) (f4624ef, cbba1f5)
- pi-profiles: `/profile <name>` with an exact name submits on the first **Enter**, and a name that is the prefix of a longer one no longer suggests the longer names. An unknown argument shows its usage as an error. In the menu, details start with "Profile: <name>" or "Tool: <name>". (7d98ec2)
- pi-read: a read without `offset`, `limit`, or `selection` uses Pi's own result rendering. (00bfad6)
- pi-null-args leaves a call unchanged when the tool schema uses `oneOf` or `$dynamicRef`, as it already did for `$ref`. (1488e74)
- pi-nested-instructions: a Bash command with a `time` or `!` prefix gives no instruction scope. Discovery errors at a turn end or session start are reported by Pi instead of being ignored. (fbb4aa1, d71befb)
- pi-session-utils: auto-naming sends the model's context instead of the raw branch, so text that a context edit omitted or a compaction replaced no longer reaches the title model. (3fd5a15)
- pi-prompt-manager: search is faster on long prompts, with the same results. (4822422)
- pi-tool-display: group headings count unknown historical outcomes as "N unavailable". A `write` that created its file shows "Created" even when its patch is unavailable. A cancellation during a retry shows Pi's retry count. Host warnings name what they turn off. (f846cf5)
- pi-tool-display: a wrongly typed field in native or pi-mcp-adapter result details drops that card's notices, instead of only the field. (f846cf5)
- pi-tool-display saves a call's facts with Pi's final tool result, and no longer saves pending facts when the session closes. (cbba1f5)
- The settings menus of pi-profiles and pi-editor-widgets, and the pi-prompt-manager browser tabs, mark the active tab or scope as `[label]`. (64e32bf)

## Fixed

### pi-editor-widgets

- "Context usage" turns to the warning colour above 70% and to the error colour above 90%, as Pi's footer does. (9bf37f4)
- A click during a pending redraw uses the last painted frame, and a press on a native widget that Pi has removed is ignored. (9bf37f4)

### pi-model-prompt

- An unreadable prompt file warns that it must be a readable regular UTF-8 file up to 1 MiB, and that rules listing it add nothing until `/reload`. (06431dd)

### pi-nested-instructions

- A Bash glob such as `cat pkg/*.ts` gives the scope `pkg`. A brace expansion with quotes inside gives no scope. (fbb4aa1)
- A tool call ID over 1,024 characters no longer suppresses a notice in its own batch. (fbb4aa1)
- A context edit that turns an unchanged notice into one text block no longer loads the notice again. (fbb4aa1)

### pi-profiles

- A deferred group that `tool_search` loads no longer turns on the group's `deny` tools. (7d98ec2)
- When the selected profile denies `tool_search`, restoration declares its deferred tools again, because nothing could load them. (7d98ec2)

### pi-prompt-manager

- Opening a collection file no longer fails when the filesystem reports a link count of 0. (4822422)
- A history entry whose temporary file failed to close no longer reports that prompt history could not be recorded. The warning says that the collection was committed. (4822422)
- An invalid shortcut list warns "pi-prompt-manager: invalid shortcuts.history; using its default.", or names `saveDraft`. (4822422)

### pi-read

- Results record and highlight `offset` and `limit` sent as numeric strings, and pi-tool-display shows their window, such as `lines 2-3`. (00bfad6)

### pi-session-utils

- `/sesh persist` cancels a pending auto-name first, so a late title can't rename the replaced session. If the switch fails after the save, the error says "Session saved to <path>, but switching to it failed: … Open it with /resume.". (3fd5a15)
- Invalid or unreadable auto-title settings name the settings file. (3fd5a15)

### pi-skills

- `/skill:` typed in a slash command's arguments shows the command's own suggestions first. (4991b8c)

### pi-smart-compact

- The status of a skipped, cancelled, or failed requested compaction shows in the warning colour, without terminal control sequences. The text that the model reads is unchanged. (899bbd8)

### pi-subagents

- A resume in which the child does no model work no longer returns the previous run's reply. (ec5b1b8)
- A job whose shell traps SIGTERM and exits after its timeout fails with "timed out after N s" instead of reporting a normal exit. (ec5b1b8)
- Resuming a task drops unanswered trailing input even when a session rename or an entry label follows it. (ec5b1b8)
- With `--tools`, a registration that only updates tool descriptions no longer turns on subagent or job tools that were turned off. (cdc955d)
- The task viewer keeps live responses with the same timestamp apart. (cdc955d)
- If another extension registers `bash` after settings load, `job` fails with "Job not started: another extension owns bash" instead of running the command. (cdc955d)
- A `/subagents list` item larger than the 50 KiB page budget is shortened with `[Text truncated]` instead of failing the command, and a task label longer than 2,000 lines or 50 KB is shortened the same way. (ec5b1b8, cdc955d)
- `/subagents` notifications contain no terminal control characters, and panel errors wrap to the panel width. (ec5b1b8)
- Input sent to an active task from a session that was just replaced fails, instead of reporting that the stopped task took it. (ec5b1b8)
- Late background usage keeps the provider and model ID apart when either contains `/`. (cdc955d)

### pi-todo

- `list` with `status: "deleted"` returns deleted todos without `includeDeleted`. When every todo is deleted, the `/todos` browser shows "N deleted · no active todos". (3638372)
- `/todos collapse`, `expand`, or `toggle` typed in full runs on the first **Enter**. (3638372)
- A lone carriage return in a description is a line break instead of being removed. (3638372)
- Duplicate IDs in `blockedBy` are stored once, and `addBlockedBy` can't grow `blockedBy` past its limit. (de07b85)

### pi-tool-display

- Cancelling a `write` while its source is being read no longer writes the file. (f846cf5)
- Diffs can emphasise character changes on lines of 1,000 characters or more, within the comparison limit. (f846cf5)
- Native `read` and `find` cards recognise Pi's truncation notices, and only compact native cards show the truncation warning. (f846cf5)
- On Windows, Git Bash and WSL paths such as `/c/repo/file` resolve to their drive paths. (f846cf5)
- Two assistant messages with the same timestamp each split groups and runs at their own position. (cdc955d)
- Cards recognise Pi's longer shell timeout status, and `!` command rows that Pi moves into the chat when a run settles separate groups and runs. (cbba1f5)

### Shared behaviour

- Fullscreen views in pi-prompt-manager, pi-todo, pi-profiles, pi-editor-widgets, and pi-subagents check Pi's private overlay-restore method against a reviewed fingerprint. When it differs, the view warns once per opening and keeps ordinary input. (64e32bf)
- Coordinator failure notices contain no terminal control characters. (bf1c369)
- The `/working-message` order menu keeps an edited project draft when you save the global order. (bf1c369)
- Several selections on one line of a pi-read result no longer carry the styling of an earlier selection into later text. (64e32bf)
- Startup errors of pi-smart-compact and pi-editor-widgets always start with the extension name. (899bbd8, 9bf37f4)

## Workspace

These changes affect forks and local development, not the `release` branch.

- The Pi development packages move to ^1.5.2, and the inspected-version pins and fingerprints in pi-smart-compact, pi-tool-display, pi-editor-widgets, pi-skills, and `@pi-mono/libs` name Pi 1.5.2. Pi 1.5.1 changed the `handleEvent`, `addMessageToChat`, `addCacheWarmingUsage`, `setToolsExpanded`, and `TuiAltScreen.doRender` hashes. (cbba1f5, 9b19924, 7db3d11)
- The catalog moves `typebox` to 1.4.7, `vite-plus` to 1.7.0 with the matching `vite` alias, and `@stylistic/eslint-plugin` to 6. It adds `eslint-plugin-slop`, and updates Tailwind, TanStack, `@types/node`, `@vitejs/plugin-react`, `eslint-plugin-boundaries`, and `unbash`. The esbuild build permission and the `vite` peer dependency rules go. (71bcd17, 8fc6de9, 61a5e2c, 2c3c504, 423aa9a, f52d548)
- Lint runs eight `eslint-plugin-slop` rules on whole files: comment length, em dashes, jargon, static-only classes, trivial functions, trivial type aliases, chained type assertions, and JSDoc. The `no-em-dash` rule replaces the pre-commit hook, which is removed. The root `format` and `format:check` scripts are removed. (2c3c504, 61a5e2c, 0de37ef, efc0a09)
- The new `lockfile:check`, which `vpr check` runs, fails when `pnpm-lock.yaml` holds a second snapshot of a Pi host package. The new `test:count` script reports test counts only. `docs:check` lists files with `git ls-files -z`, reports `file:line`, and checks extension README `jsonc` blocks and the extension count. `fingerprints:check` lists files with git and points to the method-source diff when a hash changed. (4f630af, 7dc9a2f, 7b5f217, fc96f80)
- `.gitattributes` checks out text files with LF line endings, so an `autocrlf` checkout passes the formatter. (e3822c3)
- The release job pushes the branch and the new tag in one atomic push. `build-release.ts` always builds into `.tmp/release`, and the job always fetches the `release` branch. (541acb8, 155d073)
- `@pi-mono/libs` adds `codemode-notice`, `skill-reference-settings`, `pack` in `tui/text-budget`, and `isolateEnvironment`, and `createPiLaunch` kills a timed-out Pi with `SIGKILL`. `file-mutations`, `native-tools`, and `bounded-diff` move to pi-tool-display, and `abort-race` moves to pi-session-utils. `observedSource` and several option exports go. (1fbebb0, cdc955d, 5792898, e342e9e, 0b2a2b2, aa57e00)
- `@pi-mono/utils` adds `skill-reference` and removes `fff-tools`. `provenance` moves to pi-tool-display and `search-scopes` to pi-nested-instructions. `JobEnvelope` is a union on `state`. (3947095, f0ef68d, 0b2a2b2, b063232)
- Public contracts: `pi-subagents/details` adds `launchArgItems`, the new `pi-subagents/text` exports `usageText`, `pi-smart-compact/result` adds the context status schema, and `pi-read/result` adds `windowArgumentSchema`. Display adapters can set a `path` on `create` and `edit` summary items. pi-todo result details no longer carry `action` and `params`, but older results still replay. The pi-subagents coordination protocol moves to version 3. (5792898, ec5b1b8, 58d0d9f, 00bfad6, 55170d6, de07b85, 6d4a014)
- pi-nested-instructions declares `@earendil-works/pi-ai` as a host peer. (fbb4aa1)
- The website shows current sample output, lists pi-t3-skills without pi-fff-guard, and emits both `theme-color` tags after `<HeadContent />`. Both hero images are regenerated. (de107f8, f0ef68d, aa57e00)
- The suite goes from 655 tests in 0.1.3 to 619. pi-fff-guard's tests are gone, and tests outside the listed invariants are removed, mostly in pi-read, pi-session-utils, pi-smart-compact, and `@pi-mono/libs`. The pi-t3-skills tests and the new pi-subagents and pi-tool-display features add some back. (f0ef68d, aa57e00, cdc955d, f30fc7b, 15ab4cc, 849080e, 3947095)
- Docs: a [documentation conventions](../docs/documentation.md) guide, a [release procedure](../docs/release.md), and an extension README standard that every extension README follows. Ten package `AGENTS.md` files and the generic Pi upgrade steps are removed. (8fc6de9, 4f630af, 53f916f, 0de37ef, 423aa9a)
- Agent skills: `writing-for-agents` is added, `implement` splits its review into audit and fix passes, and the audit, `code-review`, and `codebase-review` skills are trimmed to tables. (835a581, 17df602, d8f4675, 45597b0, 2414470)
