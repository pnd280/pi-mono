# 0.1.5 - 2026-11-26

## Breaking changes

- This release targets Pi 1.6.1. Update Pi with `pi update` before you run `pi update --extensions`, or install the `v0.1.4` tag to stay on Pi 1.5.2. See [Install](../README.md#install). (c4b998a, 2bfc0b7)
- pi-prompt-cloak is replaced by [pi-sysprompt-rewrite](../packages/extensions/pi-sysprompt-rewrite/README.md). If your `settings.json` lists `extensions/pi-prompt-cloak/index.ts`, change it to `extensions/pi-sysprompt-rewrite/index.ts` or remove it. The built-in replacement table is removed; to keep the previous rewrites, copy `rules` from the [example configuration](../packages/extensions/pi-sysprompt-rewrite/README.md#configuration) into global `settings.json` and run `/reload`. (0e641ee, 9263047)

## Added

- pi-sysprompt-rewrite: rewrites system prompt section bodies (including later section updates) with global regex rules in `ext.pi-sysprompt-rewrite.rules`, leaving saved sessions unchanged. See [configuration](../packages/extensions/pi-sysprompt-rewrite/README.md#configuration). (0e641ee)
- pi-sysprompt-rewrite: `ext.pi-sysprompt-rewrite.piDocsCollapse` writes the rewritten `docs` section body to a temporary file (`pi-docs.md` by default), replaces it with a one-line pointer, and moves the bash and PowerShell `PI_*` guideline into that line. Trusted project settings can override `piDocsCollapse`. See [docs collapse](../packages/extensions/pi-sysprompt-rewrite/README.md#docs-collapse). (9263047)
- pi-nested-instructions: in trusted projects below the home directory, searches subdirectories at session start for `.pi/skills/` and `.agents/skills/`, registers them through `resources_discover` for `/skill:<name>` (and pi-skills and pi-t3-skills), keeps them out of the system prompt, and appends a `pi-nested-instructions.skills` listing message when a supported tool input reaches their directory. Listings refresh on session start and follow instruction-notice lifetime rules. See [nested skill rules](../packages/extensions/pi-nested-instructions/docs/skills.md). (b0eda9e, 7a78b05)
- pi-tool-display: renders nested skill listings as expandable cards ("Listed skills (N)", "Updated skills (N)", or "Removed skills"), joins them to the preceding run, and counts them in run summary lines such as `listed skills in 1 dir`. (b0eda9e)
- pi-profiles: adds named MCP server sets in `ext.pi-profiles.mcpPresets`, toggled with `/mcp-presets` (searchable TUI menu or RPC list), `/mcp-presets <name>`, `/mcp-presets clear`, `pi --mcp-presets=<a,b>` (or `clear`), or a profile's `mcpPresets` field. Active presets persist by name and scope per branch, show in the TUI footer as `MCP: <names>`, and override clashing profile servers at run time. See [MCP presets](../packages/extensions/pi-profiles/docs/tools.md#mcp-presets). (8f22d1f)
- pi-profiles: emits one branch-aware `pi-profiles.notice` custom message when the effective profile changes between runs, rendered by pi-tool-display as a compact "Profile" status row (`Profile build → plan`, `Profile plan`, `Profile cleared (was plan)`, or `Profile unavailable (was plan)`). See [profile change notices](../packages/extensions/pi-profiles/docs/switching.md#profile-change-notices) and [status rows](../packages/extensions/pi-tool-display/docs/tools.md#status-rows). (de056ec)
- pi-tool-display: counts a `codemode` script's nested native `edit` and `write` calls in summary lines and changed-file lists with their outcomes and line counts, saving non-patch facts on `pi-tool-display.call` entries so replay matches live. See [codemode](../packages/extensions/pi-tool-display/docs/tools.md#codemode). (0091cc0)
- pi-tool-display: collapsed truncated shell cards show a "Full output could not be saved: …" warning on Pi 1.6.1's `details.fullOutputError` and clear any provisional preview path. (2bfc0b7)

## Changed

- pi-tool-display: native `read` cards warn that the model saw a placeholder instead of an image from Pi 1.6.0's `details.imageUnsupportedByModel` instead of the Pi 1.5.2 caption note. (c4b998a)
- pi-subagents: clarifies `subagent` `background` launch and wait guidance, shortens the background-update message, and forwards and sanitises Pi 1.6.1's `fullOutputError` in the task viewer. (128190a, 2bfc0b7)

## Fixed

- pi-profiles: editor top-border labelling returns a new line array instead of mutating Pi 1.6.0's cached `editor.render` output. (c4b998a)
- pi-prompt-manager: starts the collection worker with `--experimental-strip-types` instead of `--experimental-transform-types`, which Node 26 removed. (c4b998a)
- pi-tool-display: narrow status rows fall back to full-width wrapping when the continuation indent leaves too little room for the widest grapheme. (de056ec)
