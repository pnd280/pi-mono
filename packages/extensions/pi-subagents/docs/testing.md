# pi-subagents test coverage for maintainers

[Package](../README.md) · [Testing policy](../../../../docs/agents/testing.md#coverage)

This package tests task policy through real offline Pi supervisors and RPC children, with filesystem integration cases for ownership handoff failures. See the [workspace ownership rules](../../../../docs/agents/testing.md#ownership).

## Must not regress

- **Critical, e2e:** Untrusted project settings cannot affect launch configuration, and children receive the supervisor's project-trust flag.
- **High, e2e:** Completed tasks, turn aborts, user aborts, session changes, and graceful supervisor exits leave no child processes, including children that block shutdown. After supervisor SIGKILL, cooperative children stop through stdin EOF.
- **High, e2e:** Foreground calls report the child's final text and correct state; launch failures include the failed step, exit code, and stderr.
- **High, e2e:** Navigation termination and replacement isolation: tree selection (including a same-path rewind), parent-session fork, and saved-session switch immediately stop owned running subtrees, including children that block shutdown and detached descendants. Late captures, completions, and controls cannot affect the replacement binding. Ordinary foreground abort stops only its foreground subtree; new messages leave children running.
- **High, e2e:** Historical checkpoint and explicit resume isolation: the selected parent ancestry supplies the saved child conversation and descendants. Saved running tasks recover stopped, including after restart or fork. Explicit resume preserves the logical task ID in a new child session, excludes later history, and warns about incomplete tool cycles without replaying old calls. Legacy records are excluded; historical views and resume leave source files unchanged and cannot read newer external output.
- **High, e2e:** A supervisor cannot resume or abort another supervisor's tasks, and no input reaches them.
- **High, e2e and unit:** Launches and resumes report the child's usage for that call exactly once. A delivered background result adds the usage after the call returned once, also through a nested supervisor and after an extension reload. The unit case covers missing or unchanged usage snapshots and model IDs that contain a slash.
- **High, e2e:** Child dialogs reach the supervisor's client, and answers reach the requesting child with the selected value preserved even when sanitised labels collide.
- **High, unit:** Saved task records with and without run metadata (`started_at`, `ended_at`, and `usage`) parse unchanged, so older task history stays listed.
- **High, e2e:** Active children stay within configured capacity, queued launches start in FIFO order, and a full queue fails clearly.

### Background and display integration (build phase 3)

- **High, e2e (S1):** Background runs deliver exactly one completion to their owning supervisor while busy, waiting, idle, or settling in print/JSON mode; idle delivery uses prepared model context. In RPC, print, and JSON modes, a waiting supervisor continues after the first result while slower tasks run.
- **High, e2e (S2):** Moving foreground work to the background releases the call and preserves the task across turn abort. The call reports work before it returns; the delivered completion adds only the later usage.
- **High, e2e (S3):** Descendants respect configured depth and whole-tree capacity. Full nested launches fail immediately, and failed or exited subtree slots let the top-level FIFO continue.
- **High, e2e (S4):** A child's final result reaches its supervisor only after its background descendants finish and their results reach the child, also after a final error without retry.
- **High, e2e (S5):** Cancellation and graceful shutdown stop subtrees even during background and settle waits; supervisor SIGKILL leaves no cooperative descendants under the documented cleanup limit.
- **High, e2e (S6):** Relayed records preserve ownership across restart. Abort and background commands reach only owned descendants, and nested dialog answers return to the requesting child.
- **High, e2e (S7):** Compaction retains direct task IDs in model context without starting a new turn.
- **High, e2e (S8):** New follow-up or steering input and an abort end a background wait without cancelling tasks; after an abort, the later result arrives when idle. A retryable failure retries without a wait.
- **High, e2e (S9):** `subagent_abort` stops an owned active task, releases its capacity, and keeps it resumable. It rejects foreign and inactive tasks, returns a successful confirmation, and delivers no separate `cancelled` result; the supervisor stops waiting when no task remains.
- **Critical, e2e (T2):** Activity uses only validated summaries for the connected task session and collector generation; the display package owns record validation.
- **High, e2e (T5):** Late updates from a disposed task view or connection cannot affect a replacement task view or session.

### Input and transcript digests (build phase 4)

- **High, e2e (R1):** Active-task input reaches the same conversation once across running, settling, and exit races, without another capacity slot or duplicate usage or completion.
- **Critical, e2e and integration (R2):** Only owned tasks receive input. Descendant routing preserves the result destination; inactive adoption transfers ownership durably and stale or foreign owners cannot act on the task.
- **High, e2e (R3):** Read-only `show` paging covers eligible items on the checkpoint ancestry once, including validated final tool summaries, with correct cursors and ancestry-scoped cumulative usage. Thinking, arguments, outputs, and progress revisions are excluded.

## Not tested

The [activity test](../validation/activity.test.ts) holds a real child's successful RPC refresh response until its source is disposed and a replacement source has loaded another task. Releasing the response must leave the disposed source without a model or callbacks, preserve the replacement's messages, and leave both original session and checkpoint files unchanged. This covers the T5 connection boundary. It does not replace a terminal task view, delay a filesystem read, inject a failed response, or exercise every late event kind.

- RPC framing, prompt-disposition semantics, lineage, and Pi's internal trust enforcement belong to Pi. Shared libraries own their algorithms.
- macOS and Windows have no automated coverage. Tests run on Linux.
- A child that blocks shutdown can survive supervisor SIGKILL; there is no independent watchdog.
- Card appearance and task-list pagination are below the automated coverage bar.
