# Subagent test coverage

[Package](../README.md) · [Testing policy](../../../../docs/agents/testing.md#coverage)

This package tests [task](../GLOSSARY.md#tasks-and-processes) policy through real offline Pi [supervisors and RPC children](../GLOSSARY.md#tasks-and-processes); Pi owns host internals, and libs and utils own shared algorithms.

## Must not regress

- **Critical, e2e:** Untrusted project settings cannot affect launch configuration or the `subagent` description, and cannot turn on `jobs`. Children receive the supervisor's project-trust flag.
- **High, e2e:** Completed tasks, turn aborts, user aborts, session changes, and graceful supervisor exits leave no child processes, including children that block shutdown. After supervisor SIGKILL, cooperative children stop through stdin EOF.
- **High, e2e:** A [forced stop](shutdown.md) continues after the child exits until the child's process group is gone: a member of the group that ignores SIGTERM and outlives the child receives SIGKILL after the grace period, before the call returns.
- **High, e2e:** A forced stop that leaves the child's process group is reported, also when another process holds the child's output pipes. A child supervisor forwards the failure among its other stderr output, so a descendant's failure reaches the task above it. A cancelled task stays cancelled, and its result names the failure; `subagent_abort` returns the error instead of a confirmation.
- **High, e2e:** Foreground calls report the child's final text and correct state; launch failures include the failed step, exit code, and stderr.
- **High, e2e:** Tree selection (including a same-path rewind), parent-session fork, and saved-session switch immediately stop owned running subtrees, including children that block shutdown and detached [descendants](../GLOSSARY.md#tasks-and-processes). Late captures, completions, and controls cannot affect the replacement binding. After another extension cancels a tree navigation or a parent-session fork, `/subagents list` and new `subagent` calls work on the same ancestry, and a job result that waited arrives once in the next run. Ordinary foreground abort stops only its foreground subtree; new messages leave children running.
- **High, e2e:** The [selected parent ancestry](../GLOSSARY.md#history) supplies each task's latest [run](../GLOSSARY.md#tasks-and-processes) and its descendants. Running tasks recover stopped, including after restart or fork, and a run without an `end` entry shows as cancelled. Explicit resume keeps the task ID, session ID, and session file, continues the selected run in the same [child file](../GLOSSARY.md#history), excludes later runs, and warns about incomplete tool cycles without replaying old calls. A resume that omits `model` or `thinking` sends the child's provider requests with the value that the task's latest run on the selected ancestry requested, not the applied value, the supervisor's current selection, or the selection of a later run; a value in the call replaces only its own field. Historical views leave child files unchanged.
- **High, e2e:** Saved supervisor history grows by bounded [per-run records](adr/0003-keep-task-history-in-child-sessions.md#records), independent of the child's message count. Nothing is written under `<agentDir>/pi-subagents/`, and no lease directory remains after the runs end.
- **High, e2e:** A supervisor cannot resume or abort another supervisor's tasks, and no input reaches them.
- **High, e2e and unit:** Only one process, the holder of the [writer lease](../GLOSSARY.md#history), writes a task's child file. A forked supervisor cannot resume a task while the original child runs, also after the original supervisor is killed, and the file stays unchanged. After the writers exit, the next resume succeeds and removes the stale lease entries. After a release cannot remove its entry, the same process can take the lease again, and a lease that it holds still excludes another writer.
- **High, e2e and unit:** Launches and resumes report the child's usage for that call exactly once. A delivered [background result](../GLOSSARY.md#results) adds its [late usage](../GLOSSARY.md#results) once, also through a nested supervisor and after an extension reload. A task's total adds each run's usage once, live and after restart, including the usage of a child's compaction. Missing or unchanged usage snapshots add no usage, and model IDs that contain a slash retain their full ID.
- **High, e2e:** Child dialogs reach the supervisor's client, and answers reach the requesting child with the selected value preserved even when sanitised labels collide.
- **High, e2e:** Active children stay within configured [capacity](../GLOSSARY.md#tasks-and-processes), queued launches start in FIFO order, and a full queue fails clearly.
- **High, e2e (S1):** Background runs deliver exactly one background result to their owning supervisor while busy, waiting, idle, or settling in print/JSON mode; idle delivery uses prepared model context. In RPC, print, and JSON modes, a waiting supervisor continues after the first result while slower tasks run. In print and JSON modes, a result that is ready when the final reply fails without recovery still reaches the model. A turn abort cancels a background call whose child has not started; the call returns `cancelled`, and no background result follows.
- **High, e2e (S2):** [Promotion](../GLOSSARY.md#tasks-and-processes) of foreground work releases the call and preserves the task across turn abort. The call reports work before it returns; the delivered background result adds only the late usage.
- **High, e2e (S3):** Descendants respect configured depth and whole-tree capacity. Full nested launches fail immediately, and failed or exited subtree slots let the top-level FIFO continue. A resumed child has `subagent` and `subagent_abort` below `maxDepth` and does not have them at `maxDepth`, also when its session recorded them.
- **High, e2e (S4):** A child's final result reaches its supervisor only after its background descendants finish and their results reach the child, also after a final error without retry.
- **High, e2e (S5):** Cancellation and graceful shutdown stop subtrees even during background and settle waits; supervisor SIGKILL leaves no cooperative descendants under the documented cleanup limit.
- **High, e2e (S6):** Descendant records read from child session files preserve ownership across restart. Abort and background commands reach only owned descendants, and nested dialog answers return to the requesting child.
- **High, e2e (S7):** Compaction retains direct task IDs in model context without starting a new turn.
- **High, e2e (S8):** New follow-up or steering input and an abort end a background wait without cancelling tasks; after an abort, the later result arrives when idle. A retryable failure retries without a wait.
- **High, e2e (S9):** `subagent_abort` stops an owned active task, releases its capacity, and keeps it resumable. It rejects foreign and inactive tasks, returns a successful confirmation, and delivers no separate `cancelled` result; the supervisor stops waiting when no task remains.
- **High, e2e (S10):** While a task runs, also after a restart, `list` still shows the descendants of the task's earlier runs, and it never shows a descendant that is starting or running as stopped.
- **High, e2e (T2):** Activity names only the connected child's own tool calls and resets when a task resumes.
- **High, e2e (T5):** Late updates from a disposed task view or connection cannot affect a replacement task view or session.
- **High, e2e (J1):** A [job](../GLOSSARY.md#tasks-and-processes) delivers exactly one [background result](../GLOSSARY.md#results) to its supervisor when the supervisor is busy, idle, or settling after an abort. The supervisor settles while a job runs. A timeout gives a `failed` result. After compaction, the reminder keeps the job IDs in model context. A result that arrives during a turn with tool calls follows the configured [delivery timing](background-results.md#delivery-timing) within the same run.
- **High, e2e (J2):** `job_abort` stops the whole process group of an owned active job and delivers no separate result. It rejects unknown and inactive jobs. A turn abort leaves jobs running. Tree navigation, fork, session switch, reload, graceful exit, and the end of a print, JSON, or child run leave no process of the job's process group.
- **High, e2e (J3):** After a restart, [recovered jobs](jobs.md#job-history) match the [selected ancestry](../GLOSSARY.md#history); a job without a saved end shows as cancelled.
- **Critical, e2e (J4):** `job` uses the `shellPath` and `shellCommandPrefix` settings. When another extension owns `bash`, `job` and `job_abort` are hidden.
- **Critical, unit (J5):** The job log reader refuses a symbolic link, a special file, and a file that replaced the log path after the reader checked it.
- **High, e2e (R1):** Active-task input reaches the same conversation once across running, settling, and exit races, without another capacity slot or duplicate usage or completion. The result keeps the final reply that the input followed, before the input's reply.
- **Critical, e2e (R2):** Only owned tasks receive input. Descendant routing preserves the result destination. Only the supervisor that launched a task resumes it after it stops; ancestors and foreign supervisors cannot.
- **High, e2e (R3):** Read-only `show` paging covers eligible items on the selected run's ancestry once, including tool summaries that complete after a cursor was given out, with correct cursors and ancestry-scoped cumulative usage. Thinking, arguments, and outputs are excluded.
- **High, e2e (R4):** After an abort during a tool call, `show --last` returns the text and cursor of the latest assistant message with content. It skips empty `error` messages.

## Not tested

- The [activity test](../validation/activity.test.ts) covers late updates only at the connection boundary. It does not replace a terminal task view, delay a filesystem read, inject a failed response, or exercise every late event kind. A delayed file read of an earlier run is below the bar: the run reader discards it, and without that check it would show for one refresh only, because each read ends by starting the next pending read.
- RPC framing, prompt-disposition semantics, lineage, and Pi's internal trust enforcement belong to Pi. Shared libraries own their algorithms.
- macOS and Windows have no automated coverage. Tests run on Linux, and the forced-stop failure test needs `perl` to put a process into another process group.
- Coordination-protocol races during settlement and stdin EOF, and reads of large branched child files have no automated coverage. [ADR 0003](adr/0003-keep-task-history-in-child-sessions.md#runtime-checks) records the one-time probes and the open checks.
- A child that blocks shutdown can survive supervisor SIGKILL; there is no independent watchdog.
- Card appearance and task-list pagination are below the automated coverage bar.
- Job card appearance, the widget's job count, panel job rows, and the job log viewer are below the automated coverage bar.
- A job process that leaves its process group is not stopped and has no automated coverage. A cancelled session switch and a cancelled or failed branch summary have no automated coverage; the fixtures cancel only tree navigation and parent-session forks.

## Manual checks

For cards, the task panel, viewers, the widget, and command output in a terminal, use the [terminal checks](validation.md).
