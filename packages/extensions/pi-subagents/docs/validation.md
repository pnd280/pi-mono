# Subagent terminal validation for maintainers

[pi-subagents](../README.md) · [Test coverage](testing.md)

Use the [offline terminal launcher](../README.md#validation) with `delegate-display` for wide characters, control sequences, and a 12-line prompt; use `delegate-slow` for a running card. Use completed tasks for list paging. The launcher loads only `pi-subagents` and its offline provider. Compare built-in tool rows with Pi's native main transcript. The `background-late` and `background-input` children reply only after `run-release` exists in the work directory; delete it before you run them again.

| Do                                                                                     | Expect                                                                                                                                                                                                                                                                                                                                       |
| -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Press **Ctrl+Alt+S**, then **Esc**, in regular and fullscreen modes.                   | The task panel opens as with `/subagents`; closing it restores editor focus.                                                                                                                                                                                                                                                                 |
| Expand and collapse a subagent card.                                                   | Collapsed, Pi's tool box shows the description, then `status`, `model`, `usage`, and a short `task` row; a running card names its activity. Expansion adds the full task ID, non-default options, 10 prompt lines, and the result.                                                                                                           |
| Inspect preparing, waiting, starting, queued, running, and resumed calls.              | Each phase has its status; only explicit model values appear before details; live elapsed time advances.                                                                                                                                                                                                                                     |
| Inspect completed, failed, cancelled, background, steered, and queued-input calls.     | The box background marks pending, successful, and failed calls. Completed times stay fixed with a three-line reply preview after a blank row; failures show usage and an `error` row; acknowledgements stay fixed.                                                                                                                           |
| View narrow cards containing wide characters or terminal-control sequences.            | Text fits the width and keeps each value visible; labelled rows follow the [card layout](interface.md#tool-cards), stacking labels when needed. Colours survive wrapping, and child text cannot control the terminal.                                                                                                                        |

| Request a page beyond the end or with invalid paging arguments.                        | Beyond the end returns an empty page; invalid arguments produce one JSON error notification.                                                                                                                                                                                                                                                 |
| List tasks with large records.                                                         | Each page is at most 50 KiB; one item too large for a page produces an error.                                                                                                                                                                                                                                                                |
| Run `background-slow`, then open `/subagents`.                                         | The widget counts the active task and alternates between muted and dim without disappearing; the panel shows its description, model, and elapsed time.                                                                                                                                                                                       |

| View a nested tree, scroll, cycle views with **Tab**, and resize to 40 columns.        | Only descendants have branch prefixes; each tree stays in the place of its most active task; excluded parents leave visible children as roots, and rows fit the width.                                                                                                                                                                       |
| View long labels, models, and background tasks at 120 and 20 columns.                  | Rows follow the [task-panel layout](interface.md#task-rows): each task has one row, and narrow panels wrap it under the description and continue the tree guides.                                                                                                                                                                            |
| Run `delegate-slow`, let it finish, resume it, then reload and reopen `/subagents`.    | Rows show `model:thinking`, the duration, the current tool while active, `used/total` context while active and `↑ ↓` tokens after it settles, and the cost, with no zero values. Usage goes up while the task runs and adds up across the resume; the duration is for the latest run. After the reload, the values stay.                     |

| Cycle views with **Tab** and **Shift+Tab** in the panel.                               | The view counts match the tasks; each view restores its own selection. One key press changes the view once, including when the terminal sends key-release events.                                                                                                                                                                            |
| Open a task with **Enter**, press **Ctrl+O** twice, and resize to 40 columns.          | Tool calls expand, then collapse. Built-in tools, subagent calls, errors, and narrow rows match Pi's native main transcript.                                                                                                                                                                                                                 |
| Resize a transcript with long metadata values to 20 columns.                           | The title border cuts the description with `…` and drops the ID. Values wrap under the value column, and no row ends with a separator. **Esc back** remains visible, and the transcript remains scrollable.                                                                                                                                  |
| Keep a task viewer open across queued, launched, and completed updates.                | Without reopening, the title border follows the current description, and the metadata rows follow the resolved model, thinking level, and usage. While the task is active, `status` shows a spinner, the elapsed time, and `foreground` or `background`; after it ends, `✓ completed in` the duration. A failed task adds a red `error` row. |
| Open a task in regular mode, then resize to 40 columns and 12 rows.                    | The inline viewer uses 9 of the 12 terminal rows, with no outer margins. It keeps its borders, one transcript row, and the hint row with **Esc back**; metadata rows from the top fill the other rows before the other hint rows.                                                                                                            |
