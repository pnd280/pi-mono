# Subagent terminal validation for maintainers

[pi-subagents](../README.md) · [Test coverage](testing.md)

Use the [offline terminal launcher](../README.md#validation) with `delegate-display` for wide characters, control sequences, and a 12-line prompt; use `delegate-slow` for a running card. Use completed [tasks](../GLOSSARY.md#tasks-and-processes) for list paging. The launcher loads only `pi-subagents` and its offline provider.

## Task cards and command output

Compare built-in tool rows with Pi's native main transcript.

| Do                                                                                              | Expect                                                                                                                                          |
| ----------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Collapse a subagent card.                                                                       | Pi's tool box shows the description, then `status`, `model`, `usage`, and a short `task` row; a running card names its activity.                |
| Expand the card.                                                                                | Expansion adds the full task ID, non-default options, 10 prompt lines, and the result.                                                          |
| Inspect preparing, waiting, starting, queued, running, and resumed calls.                       | Each phase has its status; only explicit model values appear before details.                                                                    |
| Keep a running card visible.                                                                    | Live elapsed time advances.                                                                                                                     |
| Inspect completed, failed, cancelled, background, steered, and queued-input calls.              | The box background marks pending, successful, and failed calls.                                                                                 |
| Inspect a completed call.                                                                       | Its time stays fixed with a three-line reply preview after a blank row.                                                                         |
| Inspect a failed call.                                                                          | It shows usage and an `error` row.                                                                                                              |
| Keep an acknowledgement visible.                                                                | It stays fixed.                                                                                                                                 |
| View narrow cards containing wide characters or terminal-control sequences.                     | Text fits the width and keeps each value visible; labelled rows follow the [card layout](interface.md#tool-cards), stacking labels when needed. |
| Inspect wrapped coloured text.                                                                  | Colours survive wrapping.                                                                                                                       |
| Inspect [child](../GLOSSARY.md#tasks-and-processes) text containing terminal-control sequences. | Child text cannot control the terminal.                                                                                                         |
| Run `/subagents list --limit 1`, then follow `next_offset`.                                     | Every item appears in launch order; the final page has `next_offset: null`.                                                                     |
| Request a page beyond the end.                                                                  | It returns an empty page.                                                                                                                       |
| Request a page with invalid paging arguments.                                                   | It produces one JSON error notification.                                                                                                        |
| List tasks with large records.                                                                  | Each page is at most 50 KiB.                                                                                                                    |
| List a task with one item too large for a page.                                                 | It produces an error.                                                                                                                           |
| Inspect the registered subagent tool description.                                               | The model and thinking parameters state their defaults, with no model catalogue.                                                                |
| Run `/subagents show <task_id> --limit 1`.                                                      | One JSON notification contains a compact digest.                                                                                                |
| Run `/subagents show <task_id> --last`.                                                         | One JSON notification contains the active conversation's last text.                                                                             |

## Task panel

Run these checks in regular and fullscreen modes, except mouse checks, which require fullscreen mode.

| Do                                                                         | Expect                                                                                                                                                                                                                                     |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Press **Ctrl+Alt+S**.                                                      | The task panel opens as with `/subagents`.                                                                                                                                                                                                 |
| Close the panel with **Esc**.                                              | Editor focus returns.                                                                                                                                                                                                                      |
| Run `background-slow`, then inspect the widget.                            | It counts the active task and alternates between muted and dim without disappearing.                                                                                                                                                       |
| Open `/subagents` while that task runs.                                    | The panel shows its description, model, and elapsed time.                                                                                                                                                                                  |
| Select a foreground task and press **Ctrl+B**.                             | Foreground work becomes background work.                                                                                                                                                                                                   |
| Press **Esc** twice to close the views.                                    | Editor focus and shortcuts return.                                                                                                                                                                                                         |
| View a nested tree.                                                        | Only [descendants](../GLOSSARY.md#tasks-and-processes) have branch prefixes; each tree stays in the place of its most active task, and excluded parents leave visible children as roots.                                                   |
| Scroll, cycle views with **Tab**, and resize to 40 columns.                | Tree rows fit the width.                                                                                                                                                                                                                   |
| View long labels, models, and background tasks at 120 and 20 columns.      | Rows follow the [task-panel layout](interface.md#task-rows): each task has one row, and narrow panels wrap it under the description and continue the tree guides.                                                                          |
| Run `delegate-slow` and inspect its row.                                   | It shows `model:thinking`, the duration, the current tool while active, `used/total` context while active and `↑ ↓` tokens after it settles, and the cost. Zero token and cost values are omitted; known zero context use remains visible. |
| Let it finish, then send `resume-id <task_id>`.                            | Usage goes up while the task runs and adds up across the resume; the duration is for the latest run.                                                                                                                                       |
| Reload and reopen `/subagents`.                                            | The values stay.                                                                                                                                                                                                                           |
| Scroll multi-line list items with the arrow keys.                          | Arrows reveal the selected item.                                                                                                                                                                                                           |
| Scroll a tall item with the wheel.                                         | Scrolling reaches all its rows; the borders show no counts.                                                                                                                                                                                |
| Click a continuation row.                                                  | It opens the task under that row.                                                                                                                                                                                                          |
| Cycle views with **Tab** and **Shift+Tab**.                                | The view counts match the tasks.                                                                                                                                                                                                           |
| Return to an earlier view.                                                 | It restores its own selection.                                                                                                                                                                                                             |
| Press a view key once, including with terminal key-release events enabled. | The view changes once.                                                                                                                                                                                                                     |
| Press **Ctrl+D** on an active task.                                        | Its subtree stops.                                                                                                                                                                                                                         |
| Press **Ctrl+D** on an inactive task.                                      | The panel reports an inactive-task error.                                                                                                                                                                                                  |
| Click a fullscreen widget.                                                 | The panel opens.                                                                                                                                                                                                                           |
| Click an expanded tool card.                                               | The corresponding owned task opens.                                                                                                                                                                                                        |
| Close the view.                                                            | Editor focus returns.                                                                                                                                                                                                                      |
| Navigate the tree with a panel or viewer open.                             | Old views close.                                                                                                                                                                                                                           |
| Inspect the processes after navigation.                                    | Owned processes exit.                                                                                                                                                                                                                      |
| Inspect restored tasks.                                                    | They stay stopped.                                                                                                                                                                                                                         |

## Task transcript

Open a task from the panel with **Enter**. Compare built-in tools, subagent calls, errors, and narrow rows with Pi's native main transcript.

| Do                                                                              | Expect                                                                                                                                                                                      |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Press **Ctrl+O**.                                                               | Tool calls expand.                                                                                                                                                                          |
| Press **Ctrl+O** again and resize to 40 columns.                                | Tool calls collapse; the rows match Pi's native main transcript.                                                                                                                            |
| Resize a transcript with long metadata values to 20 columns.                    | The title border cuts the description with `…` and drops the ID.                                                                                                                            |
| Inspect the metadata at that width.                                             | Values wrap under the value column, and no row ends with a separator.                                                                                                                       |
| Scroll at that width.                                                           | The transcript remains scrollable, with the **Esc** back hint visible.                                                                                                                      |
| Keep a task viewer open across queued, launched, and completed updates.         | Without reopening, the title border follows the current description.                                                                                                                        |
| Inspect the metadata through those updates.                                     | The rows follow the resolved model, thinking level, and usage.                                                                                                                              |
| Inspect an active task.                                                         | The `status` row shows a spinner, the elapsed time, and `foreground` or `background`.                                                                                                       |
| Let the task end.                                                               | The `status` row shows `✓ completed in` the duration.                                                                                                                                       |
| Inspect a failed task.                                                          | It adds a red `error` row.                                                                                                                                                                  |
| Open a task in regular mode, then resize to 40 columns and 12 rows.             | The inline viewer uses 9 of the 12 terminal rows, with no outer margins.                                                                                                                    |
| Inspect that short viewer.                                                      | It keeps its borders, one transcript row, and the hint row with **Esc** back; metadata rows from the top fill the other rows before the other hint rows.                                    |
| Open a regular-mode viewer after selecting a task in a narrowed view.           | It stays in the regular screen and replaces the inline task list.                                                                                                                           |
| Close that viewer.                                                              | The list returns to the same view and selection.                                                                                                                                            |
| Scroll a long transcript with arrows, page keys, **Home**, and **End**.         | Only transcript rows scroll; the metadata rows, footer, and borders stay in place.                                                                                                          |
| Scroll to each end.                                                             | Border indicators count the rows hidden above and below and disappear at the corresponding end.                                                                                             |
| Scroll and drag a fullscreen scrollbar.                                         | The full-terminal viewer scrolls.                                                                                                                                                           |
| Click an action.                                                                | It opens the task on the clicked row.                                                                                                                                                       |
| Close the viewer.                                                               | Panel focus returns.                                                                                                                                                                        |
| Close both views, change the TUI mode in `/settings`, and reopen.               | Regular mode uses three-quarters of the terminal height inline; fullscreen mode uses a full-terminal overlay.                                                                               |
| View a live grandchild while `nested-background` runs.                          | Completed messages refresh through descendant updates.                                                                                                                                      |
| Keep that viewer open while a call runs.                                        | The call does not show “Interrupted”, and the viewer stays on that task.                                                                                                                    |
| View a direct child while `delegate-stubborn` runs, then reopen the viewer.     | The shell call stays running.                                                                                                                                                               |
| Inspect that child's panel row.                                                 | It names the running tool.                                                                                                                                                                  |
| Overlap a direct child's snapshot refresh with a large streamed response.       | Live tool status survives the refresh; the unfinished call is not marked “Interrupted”.                                                                                                     |
| Abort `delegate-stubborn` through the task panel, then reopen its transcript.   | Collapsed and expanded, the shell call shows its recorded abort result when captured; an unfinished call without a result shows “Interrupted”. No execution result or duration is invented. |
| Abort the foreground turn during `delegate-stubborn`, then open its transcript. | The unfinished shell call shows “Interrupted” after any partial output. No cancellation result or duration is invented.                                                                     |
| Expand an old result that references an external output file.                   | Only recorded output appears; the file is not read.                                                                                                                                         |
| Open and close a saved task view.                                               | Session and mutation-target hashes stay unchanged.                                                                                                                                          |

## Background results

The `background-late` and `background-input` children reply only after `run-release` exists in the work directory. Delete it before each check that uses either scenario.

| Do                                                                                     | Expect                                                           |
| -------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| Run `background-late`.                                                                 | The working message includes “Waiting for background subagents”. |
| Press **Esc** during the wait.                                                         | The component clears; the wait ends and the task continues.      |
| Create `run-release`.                                                                  | The result starts a new turn.                                    |
| Run `background-late`, then type `reply` during the wait.                              | The input is processed at once.                                  |
| Create `run-release`.                                                                  | The result arrives.                                              |
| Run `background-slow`, then send `abort-id <task_id>` in regular and fullscreen modes. | The card has the `subagent` layout with `⊘ aborted`.             |
| Click the abort card.                                                                  | The task opens.                                                  |
| Run `background-input`, then send `update-id <task_id> steer`.                         | The update returns immediately.                                  |
| Create `run-release`.                                                                  | The task's background result contains the added input once.      |
| Let a background result arrive.                                                        | It shows in Pi's default message box.                            |

## Jobs

Use `job-barrier` and `job-stream` for the [job](../GLOSSARY.md#tasks-and-processes) checks. Delete `job-release` in the work directory before starting either scenario.

| Do                                                                          | Expect                                                                                                                                 |
| --------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| Run `job-barrier`.                                                          | The collapsed `job` card shows the description, the first command line, `↗ returned; job continues in background`, and a short job ID. |
| Expand the `job` card.                                                      | The card adds the full job ID and the log file.                                                                                        |
| While `job-barrier` runs, start `background-slow`, then inspect the widget. | The widget shows `1 subagent · 1 job`.                                                                                                 |
| While `job-barrier` runs, open `/subagents`.                                | The "background" view lists the job with `job` in the model column.                                                                    |
| Create `job-release` in the work directory, then open `/subagents`.         | The "finished" view lists the job.                                                                                                     |
| Run `job-stream`, then press **Enter** on its `/subagents` row.             | The title border shows the `JOB` chip.                                                                                                 |
| Inspect the active job's metadata.                                          | The `status` row animates a spinner with the elapsed time, and the `command` and `log` rows show the command and the log file path.    |
| Keep the log viewer open.                                                   | It adds new lines about once a second.                                                                                                 |
| Press **PageUp**.                                                           | The view moves up one page.                                                                                                            |
| Create `job-release` in the work directory while the log viewer is open.    | New lines stop when the job ends.                                                                                                      |
| Inspect the ended job's metadata.                                           | The `status` row shows `✓ completed in` the duration and `exit code 0`.                                                                |
| Press **Esc** in the log viewer.                                            | The panel list shows again.                                                                                                            |
| Press **Ctrl+D** on an active job.                                          | The job stops, and its result arrives as a `cancelled` background result.                                                              |
| Press **Ctrl+D** on the same job again.                                     | The panel shows an inactive-job error.                                                                                                 |
| Run `/subagents jobs`.                                                      | One JSON notification lists the jobs.                                                                                                  |
| Run `/subagents show <job_id>`.                                             | One JSON notification contains the tail of the log file.                                                                               |
| Run `/subagents abort <job_id>` on an active job.                           | The job stops, and one JSON notification reports its `cancelled` outcome.                                                              |
